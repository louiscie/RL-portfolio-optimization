# RL-portfolio-optimization

This Python file uses Reinforcement Learning to predict portfolio weights for three different assets in order to maximize the expected return.
The algorithm used is PPO (Proximal Policy Optimization), a state-of-the-art reinforcement learning algorithm developed by OpenAI. Its performance in asset allocation is compared to the Markowitz Efficient Frontier, and it is shown to be 200% more profitable with a 33% improvement in the Sharpe ratio.
